# Brand Setup

Do this once per brand, before the first email. Everything here is an input Claude reads on every email after.

## The brand pack

Put these in a Brand folder next to the starter kit.

| Input | What it must contain | If it's missing |
|---|---|---|
| Claims page | What the brand can say, what it never says, how reviews and testimonials can be quoted | Stop. Write it with the founder before any copy |
| Offer sheet | Prices, codes, gifts, guarantee or trial terms, shipping rules, and exactly who qualifies for each | Stop. Check the live store and write it down |
| Logo | SVG files (the transparent vector version) in every colour variant | Get them from whoever designed the logo. Never redraw a logo |
| Fonts | The font files, installed on the computer, and restart Paper Desktop after installing | Pick a close Google font and note it as a stand-in |
| Product photos | Real photos of every product from several angles, including any hardware, packaging and close-ups | Take them on a phone in daylight. Generated images need these as references |
| Voice | Who signs the emails, spelling (Australian, British or American), words never used, emoji policy | Draft from the website and confirm with the founder |
| Platform | Klaviyo or Omnisend, the store connection, which flows already exist | Check the account |

## The reference board

Collect 20 to 30 emails the founder rates as genuinely good, as full-length screenshots, in one Figma or Paper board. Group by brand, subject line above each. For each brand note: what feels premium, what feels cheap, what to borrow, what never to do. Pick one exact email as the parent for each new email. Never average several.

## The looks

Build two to four complete looks. A look is a background, light, photography style and contrast system. Build the same email in each, side by side, and let the founder choose. Record each look in the design rules file: field colours, text colours, light, photography, best jobs, and what it must never turn into.

## The module library

In Paper, build and lock the repeating parts: main and secondary buttons, any trust badges, a benefit panel, a code pill and the footer. The footer: official logo, a few benefits, four navigation buttons, social icons, room for the live legal text, a clean hard cut from the email above. Name each module clearly so it can be copied exactly into new emails.

## The design rules file

Copy `design-rules.md`, replace the example values with the brand's, and save it in the Brand folder. Update it every time the founder corrects something, with the date, so the correction carries into every future email.
