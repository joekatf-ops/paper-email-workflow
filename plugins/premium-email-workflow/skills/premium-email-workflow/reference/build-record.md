# Build Record

| Field | Entry |
|---|---|
| Email ID | e.g. welcome-1, cart-2, campaign-spring-sale |
| Version | v001, v002 ... |
| Flow and position | e.g. Abandoned cart, email 1 of 3 |
| Timing | e.g. 2 hours after added to cart |
| Who gets it | |
| Who doesn't | e.g. carts without the qualifying product get the neutral version |
| The job (one sentence) | |
| Subject | |
