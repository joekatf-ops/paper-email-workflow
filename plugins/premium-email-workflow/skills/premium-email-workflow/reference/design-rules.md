# Design Rules

Copy this file for each brand and replace the example values. The examples are Cadian Sleep's, a sleep brand whose emails were built with this system in September 2026.

## The surface

- Build the background first. One believable surface for the full length of the email: wall, fabric, light, shadow and depth. Content sits on it
- Every join between sections is checked at actual size. The colour, light and texture match across the join, or something physical (a fold, the product, a shadow) crosses it. Never hide a bad join with a gradient
- The footer is the one deliberate hard cut
- Do not make the whole email dark for consistency. Mix dark moments with light, open space
- Gradients are occasional lighting, never the default transition between sections

## Type and buttons (at the 600 px design width)

| Element | Example value (Cadian) |
|---|---|
| Font | Host Grotesk |
| Hero headline | 58 px, line height 60 px, weight 800, letter spacing -0.045em |
| Section headline | 42 px, line height 45 px, weight 800, letter spacing -0.04em |
| Body | 26 px, line height 34 px |
| Button label | 26 px, line height 30 px, weight 800 |
| Main button | 512 x 76 px, fully rounded, 44 px from the left edge |
| Code pill | 21 px, weight 600, white pill, dark text |
| Benefit panel | 552 x 126 px, 24 px corner radius |
| Footer icons | 42 px benefit icons, 44 px social circles |
| Space above footer | 64 px of the email's own background |

At 375 px a 26 px design font displays at about 16 px; at 320 px, about 14 px. Check both before approving. If critical text is too small, make it bigger or approve a separate phone composition.

## Never

- Small labels above headlines
- A tiny button label floating in a huge button
- White text on a busy photo
- The same headline, paragraph and button formula in every section
- Product cut-outs with different light or perspective from the scene, or no contact shadow
- The same background reused for every email
- A redrawn or lookalike logo
- Text, logos, prices or buttons inside generated photos

## The looks (example: Cadian's four)

| Look | Field and type | Imagery and light | Best for | Must never become |
|---|---|---|---|---|
| Moonlit Linen | Warm white and powder blue, navy text, royal blue buttons | Cotton folds, diffuse cool light, product in the fabric | Welcome, comfort, discovery | A claim about linen fabric (it's an internal name) |
| Midnight Room | Deep navy, pale blue light, white text | Real bedroom depth, window shadows, moonlight | Night routines, dramatic offers | Neon science fiction |
| Clinical Cloud | Cool paper, silver and ice blue, navy text | Studio surfaces, close-ups, diagrams, clean cut-outs | How it works, setup, FAQs | A sterile tech dashboard |
| Editorial Bed Scene | Warm white, stone and pale oak, navy text | Daylight bedroom, hands, product in use | Lifestyle, founder notes, seasonal | The product shown wrongly (ours is an underlay, not a fitted sheet) |

## Product accuracy (example: Cadian)

Write the brand's own list. Cadian's: the sheet is a flat underlay under the customer's own fitted sheet; two elastic straps run head to foot; black connector patch with one snap; the plug is the Australian type, never generic or UK. Every generated image is checked against this list.
